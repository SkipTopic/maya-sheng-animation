# 故障恢复、备份和交接

## 1. 先识别阻塞类型

| 现象 | 优先检查 |
|---|---|
| MCP connection refused | Maya 进程、端口、MCP 配置 |
| Maya 安全警告 | 请求代码、来源、是否需要第二次结果读取允许 |
| Maya 无响应 | 模态对话框、内存、当前脚本、长任务日志 |
| 文件没有更新 | 实际保存路径、当前文件名、修改状态、重开结果 |
| 图片相同 | 相机真实名称、可见面板、lookThru、缓存和旧文件 |
| 人物突然消失 | 网格可见性、父级、姿态、当前相机和裁剪面 |
| 序列帧数不对 | playblast 区间语义、旧目录、数字排序、重复输出 |

不要连续重试同一阻塞请求。先解除模态对话框或更换到已审核的本地执行通道。

## 2. Maya 安全警告

- 审核当前代码和来源。
- 能逐次允许就不全局允许。
- 全局允许必须得到用户确认，并只用于本机可信端口。
- 记录处理方式。
- 如果 MCP 一次操作需要“执行”和“读取结果”两次连接，检查第二个警告，不要把第一个警告关闭后误判为已经畅通。

## 3. Maya 进程退出

1. 检查进程是否还存在，而不是继续等待 poller。
2. 记录当前场景和最后日志。
3. 记录尚未执行的命令文件。
4. 正常启动 Maya。
5. 做轻量只读测试。
6. 打开最近确认的工作版本。
7. 核对是否需要恢复未保存修改。
8. 不将重启前未验证的状态写成已保存。

## 4. 内存和长任务

- 控制 morph、LOD 和重复网格。
- 分批渲染并写进度日志。
- 长任务设明确完成清单，不因为“足够写报告”提前结束。
- 发生错误时保留当前版本和日志，不盲目删除整个输出目录。
- 不通过强杀进程解决普通卡顿；先检查对话框和任务状态。

## 5. 保存后回读

每个阶段版本：

```text
另存新文件
→ 记录文件大小和保存时间
→ 重新打开
→ 检查人物、骨架、相机、动画和约束
→ 重算关键指标
→ 拍一张验证图
→ 保存回读报告
```

“保存按钮执行了”不等于“所有修改已持久化”。

## 6. 阶段备份

在用户确认的阶段备份：

- 当前场景。
- 原始模型和必要中立数据。
- 当前分镜、相机映射和动作设计。
- 当前项目脚本和日志。
- 静帧、短段和验收报告。
- 原片或参考索引。
- 依赖和配置说明。
- 文件大小与 SHA-256。

备份不含账号、令牌或秘密。不要把全局 MCP 配置中的其他服务凭据复制进备份。

## 7. 备份使用

- 备份目录只读。
- 日常工作从备份复制到新目录，不直接在备份里制作。
- 恢复时保留源项目，不做整个目录覆盖式回滚。
- `.mb` 自包含不代表脚本也可自由移动；检查脚本绝对路径和启动钩子。
- 更新备份中的文档后，同步更新其哈希清单。

## 8. 交接台账

只追加，不整篇重写其他 AI 的记录。每次记录：

```text
谁、何时、完成了什么
实际修改/新增的文件
当前唯一有效工作版本
验证证据
失败或否定的方法
遗留问题
下一步及需要用户确认的事项
备份位置与校验文件
```

区分：

```text
完成
进行中
待验收
未开始
失败/仅作诊断
```

## 9. 新 AI 接手的最小信息

- 当前交接文档。
- 当前场景绝对路径。
- 原始模型和参考。
- 当前分镜与动作范围。
- MCP/本地通道状态。
- 验收图和短段。
- 保存后回读报告。
- 已知失败路径。
- 备份和校验。

不要让新 AI 从文件名称中的“final”猜测哪个版本可用；以交接文档和实际验证为准。
