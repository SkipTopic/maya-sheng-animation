# 分镜、相机调度和视口证据

## 1. 明确复刻对象

区分以下内容：

- 人物动作和视线。
- 人物之间的前后景关系。
- 景别、构图和相机高度。
- 运镜方向、速度和起止时机。
- 台词、字幕和音轨。
- 原片上的表格、时间码、平台水印等覆盖层。

默认只复刻剧情和镜头，不复制原片的表格覆盖层，除非用户明确要求。

## 2. 从参考视频建立帧证据

记录原片的：

- 分辨率、帧率、帧数、时长和音轨。
- 每镜首尾帧。
- 每镜首、中、尾和动作关键帧。
- 说话者是否在画面内。
- 前景人物及其画面左右位置。
- 镜头之间是否有承接关系。

使用 ffmpeg 抽帧时，优先按帧号或精确时间验证。不要把容器时长直接当成某一帧的精确时间而不做抽样核对。

## 3. 分镜表结构

复制 `assets/shotlist-template.csv`。最低字段：

```text
shot_id
start_frame
end_frame
dur_frames
shot_size
action
camera_move
dialogue
reference_frames
status
```

建议补充：

```text
subject
speaker
listeners
foreground
axis
props
source
notes
```

帧范围为闭区间：`dur_frames = end_frame - start_frame + 1`。

运行：

```bash
python scripts/validate_shotlist.py path/to/shotlist.csv --report path/to/shotlist_validation.json
```

不要手工转抄长分镜表而不做程序核对。

## 4. 逐镜设计表

使用 `assets/shot-plan-template.json`。每镜同时包含相机和动作，不将二者拆到互相不一致的文件中。

必须记录：

- 画面主体、说话者、听者。
- 前景人物及其画面位置。
- 视线目标。
- 头部、手部和道具动作。
- 相机 eye/aim 的起止值、焦距和帧范围。
- 对话关系轴。
- 原片参考帧和验收状态。

不要只按“动作文本中第一个人名”决定主体或说话者；反应镜头和镜头外台词会识别错。

## 5. 180° 轴线

1. 在第一批对话镜头建立人物关系轴。
2. 选择正反打所在侧。
3. 后续保持同侧。
4. 原片明确越轴时记录越轴方式和对应镜头。
5. 检查相邻镜头的人物左右位置和视线方向。

三人围桌不意味着可以围绕桌心任意取机位。每对对话者都可能有不同关系轴。

## 6. 景别和构图

不要仅按“近景=固定距离+固定焦距”生成。

同时考虑：

- 相机到头/胸/桌面的距离。
- 焦距。
- 相机高度。
- 瞄准点。
- 前景头肩占比。
- 画面宽度和人物朝向。
- 是否需要手部/桌面插入镜头。

近景、胸上景、面部特写、中景、过肩和带前景双人关系应分别验证。

## 7. 前景人物

当分镜写明“某人头在右侧前景”或“某人在左侧前景”时：

- 将前景人物实际投影到相机画面。
- 检查头肩是否入镜、是否遮挡主体。
- 检查前景在运镜起止帧的位置。
- 不将前景要求只写在 JSON 注释里。

## 8. 运镜

- 起点关键帧放在首帧，终点放在尾帧。
- 分别设置 eye 和 aim 的起止值。
- 根据相机自身方向解释左右移动，不固定修改世界 X。
- 区分上移、下移、跟随、推拉、手持晃动和定镜。
- 很短镜头不做大幅绕弧。
- 不用随机扰动或统一正弦摆动冒充运镜。
- 定镜由人物动作提供变化，不强行移动相机。

## 9. 创建和保存相机

使用 `scripts/maya_camera_tools.py`：

```python
from maya_camera_tools import create_shot_camera, keyframe_camera_move

camera = create_shot_camera(
    name="DS_S003_CAM",
    eye=[120.0, 125.0, 180.0],
    aim=[0.0, 113.0, -105.0],
    focal_length=65.0,
)
```

始终使用返回的实际名称，不假设没有自动后缀。将映射保存到 `plans/camera_map.json`，不要覆盖旧项目的映射。

正式相机使用透视投影；正交相机只用于观察/验收。近远裁剪面根据场景尺度设置，避免过宽范围导致深度精度问题。

## 10. 切换可见面板

```python
from maya_camera_tools import activate_camera
active = activate_camera(camera)
```

该函数应：

- 查找当前可见 modelPanel。
- 验证相机真实存在。
- 执行 `lookThru(panel, actual_camera)`。
- 返回面板和当前相机供日志记录。

仅设置 `modelEditor(camera=...)` 曾造成旧视口残留，不作为唯一证据。多面板布局下优先显式指定生产面板；离屏输出若出现黑帧，立即改用可见且未遮挡的视口重拍。

## 11. 静帧与短段

### 静帧

至少包含：

- 主要人物正式近景。
- 明确前景要求的镜头。
- 手部/桌面插入镜头。
- 复杂道具和最大姿态。

### 短段

选择相邻 5–6 镜，检查：

- 切镜帧是否正确。
- 人物视线是否接上。
- 前景关系是否持续。
- 运镜是否真的有起止变化。
- 动作和道具是否在切镜处跳变。
- 是否出现同图、旧图或黑帧。

未通过短段，不批量渲染全部镜头。

## 12. 相机证据报告

每镜至少保存：

```text
相机实际名称
首帧 eye/aim/rotation/focal
尾帧 eye/aim/rotation/focal
首/中/尾图片
原片对比图
前景/轴线说明
实际渲染使用记录
验收状态
```

统计唯一机位时，将位置、朝向和焦距一起比较。机位数量多不等于每个都被使用，机位重复也不一定错误；关键是是否符合原片，而不是无理由复制。
