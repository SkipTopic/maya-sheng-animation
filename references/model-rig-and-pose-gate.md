# 人物模型、绑定和姿态门槛

## 1. 先判断模型处于哪一类

| 类型 | 下一步 |
|---|---|
| 只有静态网格，无骨架 | 进入骨架规划、绑定和权重阶段，不直接做动画 |
| 有骨架但未蒙皮 | 检查骨架姿态，绑定后再做标准动作测试 |
| 有骨架和蒙皮，来源 FBX | 检查单位、坐标、骨名、权重和姿态 |
| 来源 PMX/MMD | 先通过可信转换链处理 IK、SDEF、表情和坐标 |
| 已有动画或约束 | 保存基准并识别输入连接，避免覆盖现有动画 |
| 已严重扭曲 | 停止后续制作，调用人物修复 Skill |

“能打开模型”不代表“能完成目标动画”。

## 2. 只读模型审计

使用 `scripts/inspect_maya_project.py`，记录：

- 场景文件和修改状态。
- 单位、帧率和播放范围。
- 非中间网格、顶点数、包围盒、可见性和父级。
- skinCluster、blendShape、SDEF、Delta Mush、IK 和约束。
- 关节数量、名称、层级和关键关节世界位置。
- 材质、贴图路径、外部 reference 和未知节点。
- 当前动画曲线和关键帧。
- 相机实际名称。

将报告保存到项目 `logs/`，不要只留在对话里。

## 3. 格式和转换

### FBX

检查：

- 单位缩放是否导致人物过高或过小。
- 坐标系转换是否留在合法父级。
- 骨架与网格是否使用一致的转换。
- 骨名是否有命名空间或自动后缀。
- 是否带大量 LOD、morph、辅助网格或多余骨架。

### PMX/MMD

- 使用用户认可的 Blender + mmd_tools 转换链。
- 转换前记录插件版本和缩放。
- 清除或明确处理 MMD 约束/IK 的方式。
- 保留骨骼映射和原始模型。
- 检查 SDEF 辅助结构和大角度弯臂。
- 不把转换后出现的日文转义骨名问题掩盖成 root 动画。

需要下载 Blender 插件或模型依赖时，先询问并遵守用户的网络限制。

## 4. 无骨架模型的绑定流程

不要把自动绑骨和正式动画合并为一步。

### 4.1 骨架规划

- 确定骨盆、脊椎、颈、头、肩、上臂、前臂、手、大腿、小腿、脚。
- 根据模型实际几何放置关节，不套用固定坐标。
- 明确左右侧、骨骼朝向和旋转轴。
- 保持统一命名和层级。
- 手指骨按项目需要建立；用户禁止手指动画时仍可保留骨骼但不做动画。

### 4.2 绑定前检查

- 网格处于稳定参考姿态。
- 变换、法线、比例和拓扑已检查。
- 关节不在体外，关节链方向合理。
- 主网格父级和变换有记录。
- 原始模型已备份。

### 4.3 蒙皮和权重

- 肩、肘、腕、髋、膝、踝保留合理权重过渡。
- 袖口、衣摆和分层壳需要单独检查。
- 不用高迭代平滑变形器掩盖错误权重。
- 记录绑定节点和权重操作方法。

### 4.4 标准测试姿态

至少测试：

- 头部左右轻转。
- 手臂自然下垂。
- 小臂小幅弯曲。
- 目标动作所需的最大弯臂。
- 坐姿大腿前伸、膝盖弯曲、小腿向下。
- 脚底落地。

任何测试造成明显破面、扭曲或关节错位，都先修绑定，不进入动画。

## 5. 单位和坐标系

- 查询 `cmds.currentUnit(q=True, linear=True)`。
- 使用世界包围盒确认人体高度和坐姿高度。
- 不用网格缩放补偿骨架比例错误。
- 保留用于 FBX 坐标转换的 `-90°` 和 `×100` 等合法父级变换。
- 读取局部旋转时，同时读取世界矩阵和父级。
- 不用局部 `rotateX` 单独推断前倾角。

## 6. morph 和表情数据

- 统计 morph 数量和实际总顶点数。
- 不需要嘴型时，不导入完整口型 morph。
- 只保留需要且经过验证的身体网格和必要表情。
- 清理后另存测试场景，不覆盖原始模型。
- 大模型在约 8GB 内存机器上尤其需要控制网格规模。

## 7. 姿态基线

恢复或制作姿态时：

1. 从原始模型提取中立局部变换。
2. 保留人物组的落座/地面补偿。
3. 使用世界位置判断躯干直立。
4. 使用显式两段 IK 修腿和手臂。
5. 恢复脚底或手掌的合理世界朝向。
6. 检查桌椅、地面和道具接触。
7. 保存后重开验证。

配套修复 Skill：

```text
maya-character-pose-recovery
```

在当前示例项目中位于 `解决人物模型的 Skill/`。迁移时单独导入该 Skill，不硬编码示例绝对路径。

## 8. 模型/绑定门槛通过条件

- [ ] 主网格和骨架均存在且可见。
- [ ] 蒙皮、权重和父级关系可解释。
- [ ] 骨名和层级已记录。
- [ ] 单位和人体尺度正常。
- [ ] 头部和手部目标动作已做小幅测试。
- [ ] 目标最大弯臂不会破袖。
- [ ] 坐姿或初始姿态通过四视图。
- [ ] 碰撞、脚底和接触区域经过检查。
- [ ] morph/辅助网格没有超出机器资源。
- [ ] 保存后重开结果一致。
- [ ] 所有剩余限制已写入任务简报。

通过后才开始正式分镜场景和动画。未通过时明确写“模型/绑定待修复”，不要继续堆相机和全片帧数。
